Find any song in your playlist

Amazon Music on the web has no native playlist search.

Find in Playlist for Amazon Music is a free Microsoft Edge extension. On a playlist page, type part of a title or an artist and choose Find next. The match is a case-insensitive substring. It works where Ctrl+F doesn't, and it automatically scrolls to load songs on long playlists. It scrolls the row into view. It does not play it. It only needs to scroll to a song once, and it will remember that song's position in the playlist.

The search button hides when you are not viewing a playlist, so it does not clutter the player. Search stays hidden on the queue and lyrics.

Install

From Microsoft Edge Add-ons

The easiest way: install it from the official store with one click, and Edge keeps it updated automatically. Store copies never contact GitHub.

Get it on Microsoft Edge

Load unpacked (Chrome and other browsers)

  1. Download the ZIP from the latest release and unzip it (or clone the repo and use its extension folder).
  2. Open edge://extensions (in Chrome: chrome://extensions).
  3. Turn on Developer mode.
  4. Click Load unpacked and pick the folder that contains manifest.json.
  5. Open a playlist on music.amazon.com.

Where it runs

Only playlist pages on the English Amazon Music sites: music.amazon.com, .ca, .co.uk, .com.au, .in, and .ae. Other pages on those sites do not show the button. Other regional sites are not included.

The in-page button tooltip reads Find in playlist 1.0.9. Press Esc while the search box or the button is focused to close the box. If you scroll away from the current match, the next Find next returns to the nearest match already found.

Microsoft Add-ons store updates can take up to a week because Microsoft reviews each one. The GitHub version is always the newest. See what's included.

Privacy

No account

There is no sign-in, no analytics, and no server of ours. Removing the extension removes it. Nothing is stored in extension storage.

Search stays on the page

Titles and artist names are read from the playlist already open in your browser. They are not sent anywhere.

What it does not do

It does not play the row, read your Amazon account or cookies, or download lyrics. Playlist contents never leave the page.
