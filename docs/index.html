Find the next song in the playlist

Find in Playlist for Amazon Music is a free Microsoft Edge extension. On an Amazon Music playlist page, a floating button sits under the lyrics translator button. Type part of a title or an artist and choose Find next. The match is a case-insensitive substring, and songs that are not loaded yet are included. It scrolls the row into view. It does not play it.

What it does

Only on Amazon Music playlist pages. Nothing here plays the song.

⌕

Find next

Type part of a title or an artist, then Find next. The match is a case-insensitive substring of the title or the artist.

↓

Songs not loaded yet

The playlist does not have to be fully loaded. Find next scrolls so later tracks can be searched, then stops on the next match.

↩

Wraps once

After the last match, the next search goes back to the first match one time. The box says Wrapped.

▶

Does not play the row

The matching row is scrolled into view and the matching text is highlighted. Playback is left alone.

—

Hides when lyrics or the queue is open

The button is removed while the lyrics view or the play queue is open, and the search box closes.

⧉

Sits under the translator

The find button is directly under the lyrics translator button. The translation panel stacks above the search button, and opening translation closes the search box.

Works with Lyrics Translate

The two extensions work together on Amazon Music with seamless compatibility: the translator button and the find button stack, and opening lyrics does not fight search.

Stacked buttons

The translator button stays on top. Find in Playlist is the button under it, on the same right edge. The search box opens below that.

Opening translation closes search

When the translation panel opens, the search box closes. The panel stacks above the search button, so the two controls do not cover each other.

Install

Load unpacked

  1. Download the ZIP from GitHub (Code, then Download ZIP) and unzip it, or clone the repo.
  2. Open edge://extensions (in Chrome: chrome://extensions).
  3. Turn on Developer mode.
  4. Click Load unpacked and pick the folder that contains manifest.json.
  5. Open a playlist on music.amazon.com.

Get it on GitHub

Where it runs

Only playlist pages on the English Amazon Music sites: music.amazon.com, .ca, .co.uk, .com.au, .in, and .ae. Other pages on those sites do not show the button. Other regional sites are not included.

The in-page button tooltip reads Find in playlist 1.0.8. Press Esc while the search box or the button is focused to close the box. If you scroll away from the current match, the next Find next returns to the nearest match already found.

Privacy

No account

There is no sign-in, no analytics, and no server of ours. Removing the extension removes it. Nothing is stored in extension storage.

Search stays on the page

Titles and artist names are read from the playlist already open in your browser. They are not sent anywhere.

What it does not do

It does not play the row, read your Amazon account or cookies, or download lyrics. Playlist contents never leave the page.
