Find in Playlist for Amazon Music · Version 1.1.0 · October 3, 2026

This page describes the Microsoft Edge extension "Find in Playlist for Amazon Music", published by NoodlesNom. The extension is not affiliated with Amazon. The developer collects no data.

What it does

  • It is a content script on the English Amazon Music sites: music.amazon.com, .ca, .co.uk, .com.au, .in, and .ae.
  • The button and the search box appear only on playlist pages. They stay hidden on the queue and the lyrics view.
  • It reads song titles and artist names that are already shown in that playlist.
  • It works where Ctrl+F doesn't, and it automatically scrolls to load songs on long playlists, then scrolls the matching row into view and highlights the matching text.
  • A song that has already been scrolled past is jumped to immediately when searched. After it scrolls to a song once, it remembers that song's position in the playlist while the page stays open. That memory stays in the page. Nothing is written to extension storage.
  • The current search is kept in the page while that playlist stays open. Nothing is written to extension storage. There is no background script and no account.

What it does not do

  • It does not send playlist contents, titles, or artist names anywhere. Search is local to the page.
  • It does not use analytics, trackers, or a server run by the developer.
  • It does not read cookies, your Amazon account, or your listening history.
  • It does not play, pause, or skip the row.
  • It does not download or display lyrics.
